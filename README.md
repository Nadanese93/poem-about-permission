## The poem

> All morning I rehearsed the sentence,
> may I come in,
> until it fit my mouth.
> She answered yes
> before I'd finished asking.
> The door, it turned out,
> was never locked.
> Only my hand was.

## How to run

Requires Python 3.13 (standard library only, no network, deterministic).

```bash
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes the poem to `$MAKEFUN_OUTPUT_DIR/entry.txt` (UTF-8,
1–280 characters).
